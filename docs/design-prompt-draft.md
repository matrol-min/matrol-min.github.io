# Claude Design 프롬프트 초안 (v2 — 시안 3종 제안 요청, 영문 페이지 우선)

## 목표
GitHub Pages(정적 HTML/CSS, 빌드 도구 없이)로 운영할 **학술 CV(Academic CV) 웹사이트**의 **영문 페이지 디자인 시안 3가지**를, 서로 뚜렷하게 다른 방향으로 제안해 달라.
(하나로 조합하지 말고 3개를 각각 독립된 완성안으로 제시. 비교 후 하나를 고른다.)
이전 버전(Jekyll modern-resume-theme)은 가운데 정렬 섹션 제목·카드형 레이아웃 때문에 학술용으로 어색해 폐기했다.

## 사용자 / 맥락
- 민성용 (Sung-Yong Min), Ph.D. 신소재공학(POSTECH). 삼성전자 영상디스플레이사업부 수석 엔지니어. 마이크로LED 접속·수리 공정.
- 읽는 사람: 학회·채용 심사자·공동연구자. 목적: 업적을 빠르게 훑고, 필요하면 인쇄/PDF로 낸다.
- **이번 범위는 영문 페이지만.** 이름·직위·이메일만 공개(전화번호 비공개).
- 한글 페이지는 나중에 추가. **언어와 무관한 구조**로 설계: 라벨/텍스트는 한 곳에서 주입, 레이아웃은 언어별로 복제하지 않고 `lang` 속성·폰트 스택만 바꾸면 되게. KO/EN 전환 UI는 지금 만들지 않는다(자리만 확보 가능).

2. `2-modern-professional.png` — 회색 사이드바 + 파란 포인트색, 세로 타임라인(점+선), 제목 밑줄.
3. `3-bw-simple.png` — 회색 헤더 밴드, 자간 넓은 대문자 제목, 무채색, 인쇄 친화적.
4. `4-minimalist.png` — 진한 남색 사이드바, 본문은 '날짜/기관 | 직함/설명' 2열 행 구조, 제목 밑줄.
- 공통 분위기: 차분, 정보 밀도 높음, 장식 최소, 굵은 산세리프 제목 + 회색 계열 작은 본문, 강조색 1개 이하.
- **요청: 위 스타일에서 영감을 받아, 레이아웃 철학이 서로 다른 3가지 시안.** 예) (A) 단일 컬럼 + 상단 헤더, (B) 좌측 사이드바 + 본문, (C) 날짜 열 중심의 표형 행 구조. 3안 모두 아래 요구사항을 동일하게 충족.

## 공통 디자인 조건
- 폰트: 영문 산세리프(Poppins·Montserrat·Inter 계열 등, 외부 의존 최소·시스템 폰트 폴백). 본문 좌측 정렬.
- **최소 폰트 크기 기준 (가독성, 반드시 준수):**
  | 용도 | 화면(px, rem 사용) | 인쇄(A4, pt) |
  |---|---|---|
  | 본문·소개·경력 설명 | 16 이상 (권장 16~18) | 11 이상 (최소 10) |
  | 논문/특허 목록의 서지정보·항목 | 15 이상 (권장 16) | 10 이상 |
  | 배지·날짜·번호·캡션·Back 링크 등 보조 | **14 이상** (절대 하한) | 9 이상 (절대 하한) |
  | 항목 제목 | 본문 이상(16~18) | 본문 이상 |
  | 섹션 제목 / 이름 | 22~28 / 32 이상 | 14~16 / 20 이상 |
  - 위 하한 미만의 텍스트는 어떤 요소·모바일 포함 어떤 화면 폭에서도 만들지 않는다(`clamp()`·반응형 축소로도 하한 유지).
  - 줄 간격: 본문 1.5~1.6, 목록 항목 1.4 이상. 한 줄 길이 약 45~80자. 단위는 `rem`, 사용자 글자 크기 설정과 200% 확대에서도 레이아웃이 깨지지 않을 것. 하한은 CSS 변수(예: `--fs-min`)로 한곳에 정의.
  - 인쇄에서 쪽수를 맞추려고 글자를 줄이지 말고, 쪽수가 늘어나게 둘 것.
  - 근거: 웹 본문 16px이 사실상 표준이고 WCAG는 200% 확대 가능성을 요구([reciteme](https://reciteme.com/us/news/accessible-font-size/), [A11y Collective](https://www.a11y-collective.com/blog/wcag-minimum-font-size/)). 인쇄 본문은 일반 10pt 최소·12pt 권장, 각주·캡션은 8~9pt까지 허용([digital.govt.nz](https://digital.govt.nz/standards-and-guidance/design-and-ux/accessibility/designing-documents-for-print)). 이 문서는 목록이 길어 인쇄 11pt 본문 / 10pt 목록으로 절충.
- 색: 단일 강조색 1개(기존 #477dca 계열 가능) + 무채색. 라이트/다크 대응.
- 반응형: 모바일(400px)·데스크톱. 사이드바 안은 모바일에서 1열로 접힘.
- **프로필 사진 자리 필수:** 참고 시안처럼 헤더/사이드바에 사진 영역(원형 또는 정사각 크롭, `object-fit: cover`)을 둔다. 3안 모두 포함, 모바일에서도 유지(크기만 축소), 인쇄에도 표시. 사진 파일이 없을 때를 위한 플레이스홀더 처리 포함. 실제 파일: `cv-data/SYMin-050.jpeg`(교체 가능하게 경로 한 곳 지정), `alt` 텍스트 제공.
- 접근성: 충분한 대비, 키보드 포커스 표시, 의미 있는 heading 구조.

## 섹션 구성과 순서
Profile → **Research Summary(실적 요약)** → Experience → Education → Research Interests → Research Projects → Skills → Awards → **Publications(International → Domestic)** → **Patents(International → Domestic)**

## 핵심 요구 1 — 실적 요약 + 점프 링크
- 실적 숫자는 **데이터에서 자동 집계**(기존 아카이브 기능과 동일). 디자인에서는 숫자 placeholder만 두고 값은 빌드 시 주입된다고 가정.
- 지표(샘플 값): 논문 31 · 1저자 10 · 특허 출원 153 · 등록 70. 숫자 카드/한 줄 표 등 표현은 시안마다 다르게.
- 요약 영역에 **목록 이동 링크 4개**, 순서 고정:
  1. International Papers → `#intl-papers`
  2. Domestic Papers → `#dom-papers`
  3. International Patents → `#intl-patents`
  4. Domestic Patents → `#dom-patents`
  각 링크 옆에 그룹별 건수 표시(현재 특허: 국제 108 / 국내 45. 논문은 국내/국제 구분 데이터가 아직 없어 샘플 값).
- 긴 목록에서 요약으로 돌아오는 "Back to summary" 링크(인쇄 시 숨김).

## 핵심 요구 2 — 논문/특허 목록
1. 논문 31편, 특허 153건으로 매우 길다. 화면에서는 연도별 접기/펼치기나 "더 보기" 등으로 훑기 쉽게 하되, **접힌 상태가 인쇄에 영향을 주면 안 된다.**
2. 논문 항목: 제목 / 저자(본인 굵게) / 저널·연도·doi / 배지(1저자·교신). 특허 항목: 제목 / 발명자 / 번호 / 배지(등록·출원).
3. 대표 논문(6편) 강조 영역은 선택 사항.
4. 소제목 4개(International/Domestic Papers, International/Domestic Patents)는 분명한 divider로.

## 핵심 요구 3 — 인쇄(A4) 연속 페이지
- `@media print`: **A4 세로**, 여백 15~20mm. 요약·경력·…·논문 전체·특허 전체가 **끊김 없이 이어지는 연속 페이지**로 인쇄(1~2쪽 제한 없음, 목록 분량만큼 여러 쪽).
- 인쇄 시 접힌 항목 **전부 펼침**, 더 보기/내비/Back 링크/검색 UI 숨김, 레이아웃은 단일 컬럼 또는 안정적인 2열로 단순화, 배경색 최소화(흑백 출력에서도 구분 가능).
- 목록 항목은 쪽 중간에서 갈리지 않게(`break-inside: avoid`), 섹션/소제목 제목이 쪽 맨 아래 홀로 남지 않게(`break-after: avoid`). 쪽 번호/머리글은 선택.
- 3개 시안 모두 **화면 모습 + 인쇄 모습(첫 쪽, 목록 쪽 1장)**을 함께 제시.

## 산출물 형식
- 단일 `index.html`(영문) + `style.css`(+ 선택적 소량 JS). 외부 의존 최소, 빌드 도구 없음.
- 데이터는 `cv-data/*.yml`을 JSON으로 변환해 렌더링하는 구조 가정. 디자인 단계에서는 논문·특허 각 5건 이상 샘플(국제/국내 모두 포함).
- 한글 페이지 추가를 위해 섹션 제목 등 라벨은 한곳에 모아 하드코딩 최소화.
