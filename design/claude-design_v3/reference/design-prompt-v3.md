# Claude Design 후속 프롬프트 (v3 — 시안 C 기준 확정안)

앞서 주신 시안 3종(A/B/C) 중 **C(날짜 열 표형 행)를 기준안으로 확정**합니다. 새 시안을 더 만들지 말고, **C 하나를 아래대로 수정한 최종 시안 1개**(Desktop 1280 / Mobile 400 / 인쇄 A4 첫 쪽 / 인쇄 A4 목록 쪽 4개 상태)로 다시 만들어 주세요. 이전 요구사항(영문 전용, 사진 자리, 최소 폰트 기준표, 점프 링크 4개, 인쇄 연속 페이지)은 모두 그대로 유지합니다.

## 1. 데이터 표기를 실제 YAML과 통일 (필수)
시안에 쓴 샘플 표기는 실제 데이터와 달랐습니다. 아래 값만 사용해 주세요.

- **논문 번호 제거:** Publications(International/Domestic Papers) 목록의 `[1]`, `[2]` … 번호 열을 삭제합니다. 번호 열이 사라진 만큼 제목이 왼쪽으로 붙도록 그리드를 조정하고, 시맨틱은 `<ol>` 유지(번호 표시만 `list-style: none`). 특허 목록의 번호도 같은 이유로 삭제해 일관되게 합니다.
- **논문 `role` 값** (YAML: `first` / `corresponding` / `co`):
  - `first` → 배지 **"1st author"** (solid)
  - `corresponding` → 배지 **"Corresponding"** (outline)
  - `co` → **배지 없음**
  - `first`이면서 교신인 경우는 없고, 한 논문에 배지는 최대 1개입니다("1st author"와 "Corresponding" 동시 표시 금지).
- **특허 `status` 값** (YAML: `registered` / `pending`):
  - `registered` → 배지 **"Registered"** (solid)
  - `pending` → 배지 **"Pending"** (outline)
  - 시안의 "Granted" / "Filed"는 모두 이 표기로 교체.
- **실적 요약 지표 라벨**도 같은 용어로 교체: `Papers 31` · `First-author 10` · `Patents filed 153`(출원 전체) · **`Registered 70`**("Patents granted" → "Registered patents").
- **특허 항목의 필드:** 제목 / 발명자 / 번호 한 줄(`number` 문자열을 그대로 표시, 예: `10-2011-0100762 (2011.10.04), 등록 10-1374401 (2014.03.07)`처럼 길 수 있으니 줄바꿈 허용) / 배지. 시안의 `관청 · 날짜` 분리 표기는 쓰지 않습니다(데이터에 별도 필드 없음).
- **논문 항목의 필드:** 제목 / 저자(본인 `S.-Y. Min` 굵게) / `venue` 문자열 그대로(예: `Adv. Funct. Mater., 20, 1797-1802 (2010)`) / doi가 있을 때만 링크(현재 대부분 비어 있음 → 비어 있으면 doi 자리를 렌더하지 않음) / 배지.
- **샘플 건수 수정:** 그룹 건수는 International Papers **27**, Domestic Papers **4**, International Patents **108**, Domestic Patents **45**. (시안의 24/7은 틀린 샘플.) 총합 31 / 153도 맞춰 주세요.

## 2. A·B 시안에서 가져올 부분 (C에 추가)
C의 구조(왼쪽 섹션 제목 열 | 날짜 열 | 내용)는 그대로 두고 아래만 이식합니다.

1. **B의 상단 고정 이동줄(sticky)**: 스크롤 중에도 점프 링크 4개(건수 pill 포함)에 접근할 수 있도록, 목록 영역(Publications부터)을 지날 때 화면 상단에 얇게 고정되는 바를 추가. 건수 pill은 B처럼 연한 강조색 배경의 둥근 pill. 인쇄에서는 숨김. 높이는 얇게(≈44px) 하고 한 줄에 4개가 모바일에서는 가로 스크롤 없이 2×2로 접힘.
2. **A의 연도 구분**: 긴 목록(특히 특허 153건)에서 훑기 쉽도록, 각 그룹 안에서 **연도가 바뀔 때만 연도 소제목 행**을 보이고 같은 연도 항목은 그 아래에 이어 붙임. (C의 날짜 열은 연도 반복 표기 대신 연도를 한 번만 표시.) 접기/펼치기는 C의 "+ N more"를 유지하되 기본 노출은 **그룹당 최근 연도 3건**.
3. **B의 타임라인 점/선은 쓰지 않음**(C의 표형 행 유지). 사이드바도 쓰지 않음.

## 3. 변경하지 말 것
- C의 폰트(IBM Plex Sans), 색 토큰, 사진 자리(정사각, 헤더 왼쪽), 섹션 순서, 앵커 id, 인쇄 규칙(2열 유지, 접힌 항목 전부 펼침, 배지 흑백화), 최소 폰트 크기 기준표.
